# ADR-005: 语法树发射生成代码

| 字段 | 值 |
|------|-----|
| **状态** | Accepted |
| **日期** | 2026-05-05 |
| **关联 RFC** | 无 — 工程决策（CHANGELOG 0.3.0） |

## 背景

早期生成器使用字符串插值拼接 C# 源码，难以保证格式、nullable 与转义正确，Review 困难。

## 决策

所有生成器改为通过 **Roslyn 语法工厂 / 语法树** 构建 `CompilationUnit`，再 `NormalizeWhitespace` 输出。禁止新增裸字符串大块拼接（除特性参数表达式等必须保留用户原文的场景）。

## 后果

- **正面**：结构正确性更高；重构更安全。
- **负面**：代码量略增；学习曲线高于字符串模板。
